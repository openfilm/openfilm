### পরিচিতি

OpenFilm যেকোনো কোডিং এজেন্টকে ভিডিও এজেন্টে পরিণত করে, সঙ্গে দেয় এডিটর, যাতে এজেন্টের বানানো সবকিছুই আপনি বদলাতে পারেন।

আপনি আর এজেন্ট একই ভিডিওতে একসঙ্গে, লাইভ কাজ করেন। এজেন্ট যা বদলায়, ঘটার সঙ্গে সঙ্গেই আপনি তা দেখতে পান; আপনি যা বদলান, এজেন্টও তা দেখে। বেশিরভাগ কাজ এজেন্টই করে; আপনি যেকোনো কিছুর দিকে দেখিয়ে বদল চাইতে পারেন, কিংবা নিজেই করে নিতে পারেন।

- **ভিডিও বানায় এজেন্ট।** Claude Code, Codex, অন্য যেকোনো কোডিং এজেন্ট, অথবা ডেস্কটপ অ্যাপের বিল্ট-ইন এজেন্ট ব্যবহার করুন। সে ফুটেজ, মিউজিক আর ভয়েস খুঁজে আনে, প্রতিটি শট লেখে, তারপর সেগুলো জুড়ে দেয়, আর আপনি পুরোটা চোখের সামনে দেখেন।
- **যেকোনো কিছুর দিকে দেখান।** একটি ক্লিপ, একটি মুহূর্ত, টাইমলাইনের একটি অংশ, ফ্রেমের একটি জায়গা, সাবটাইটেলের একটি লাইন, ক্যানভাসের একটি কার্ড। সেটির দিকে দেখিয়ে বলুন কী চান, এজেন্ট ঠিক বুঝে যায় আপনি কী বোঝাচ্ছেন।
- **নিজের হাতে বদলান।** যেকোনো শটের ভেতরে যেকোনো এলিমেন্ট সরান, ছোট-বড় করুন, ঘোরান, লেখা নতুন করে টাইপ করুন, রং, ফন্ট আর সাইজ বদলান, অ্যানিমেশন দিন, এমনকি শব্দে শব্দে। টাইমলাইনে ক্লিপ ট্রিম, স্প্লিট আর আগে-পরে সাজান, স্পিড, ভলিউম আর ফেড বদলান, ক্রপ, কালার গ্রেড আর ব্যাকগ্রাউন্ড কেটে বাদ দিন, এবং সাবটাইটেল ও ভয়েস-ওভার এডিট করুন। আপনার এডিট একই ফাইলে জমা হয়, আর এজেন্ট সেগুলোর ওপরেই কাজ এগিয়ে নেয়।

### ইনস্টলেশন

**ডেস্কটপ অ্যাপ।** [macOS বা Windows-এর জন্য ডাউনলোড করুন](https://github.com/openfilm/openfilm/releases/latest)। যা যা লাগে সব এতেই আছে, একটি বিল্ট-ইন এজেন্ট পর্যন্ত, আর আপনি যদি আগে থেকেই Claude Code বা Codex ব্যবহার করেন, সেগুলোর সঙ্গেও এটি কাজ করে।

**আপনার নিজের কোডিং এজেন্ট।** স্কিলটি যোগ করুন (Node 22.2+ আর ffmpeg লাগবে), তারপর একটি ভিডিও চেয়ে নিন:

```bash
npx skills add openfilm/openfilm
```

> আমার CLI-এর জন্য মিউজিকসহ 20 সেকেন্ডের একটি লঞ্চ ভিডিও বানাও।

### এডিটর

প্রতিটি এডিটর একই ভিডিওতে কাজ করার আলাদা একটি উপায়, আর প্রতিটিতেই আপনি ও এজেন্ট একসঙ্গে কাজ করেন। OpenFilm-এর সঙ্গে আসে চারটি এডিটর, আর নানা ধরনের মানুষের জন্য আরও অফিশিয়াল এডিটর তৈরি হচ্ছে: এত সহজ যে যে-কেউ সঙ্গে সঙ্গে ব্যবহার করতে পারে, আর যাঁরা চান তাঁদের জন্য পেশাদার ওয়ার্কবেঞ্চ। এডিটরগুলো কমিউনিটির ওপেন স্ট্যান্ডার্ড মেনে চলে, তাই যে-কেউ নিজের এডিটর বানিয়ে শেয়ার করতে পারে।

- **স্ক্রিনিং**: পূর্ণ আকারে ভিডিও দেখুন। কোনো মুহূর্তে ক্লিক করুন, একটি অংশ জুড়ে টেনে নিন, বা ফ্রেমের কোনো জায়গায় বৃত্ত আঁকুন, এজেন্ট বুঝে যায় আপনি কীসের দিকে দেখাচ্ছেন।
- **এডিট**: ক্লিপ, টেক্সট, ক্যাপশন, ভয়েস-ওভার আর সাউন্ডের পূর্ণাঙ্গ টাইমলাইন। শটের ভেতরের যেকোনো কিছু সরান, ছোট-বড় করুন, স্টাইল বদলান। ভিডিও এক্সপোর্ট করুন, অথবা টাইমলাইনটি নিয়ে যান Final Cut Pro, Premiere Pro বা DaVinci Resolve-এ।
- **ক্যানভাস**: পরিকল্পনার বোর্ড, যেখানে নোট, ছবি, ক্লিপ আর ভয়েস পাশাপাশি থাকে। আপনার সার্ভিস দিয়ে প্রতিটি জেনারেট করুন, তারপর ক্রম অনুযায়ী টাইমলাইনে পাঠান।
- **কালার**: স্কোপ, কালার হুইল আর কার্ভ দিয়ে প্রতিটি ক্লিপ গ্রেড করুন, ক্যামেরার লগ ফুটেজ থেকে বা `.cube` LUT দিয়ে। প্রিভিউতে যা দেখেন, এক্সপোর্টেও ঠিক তা-ই পান।

চারটি এডিটরই একটি লাইব্রেরি ভাগ করে নেয়: আপনার নিজের ফুটেজ ফোল্ডারে সাজানো থাকে, কপি না করে লিংক করা থাকে, আর সরিয়ে নিলেও আবার খুঁজে পাওয়া যায়; পাশেই থাকে OpenFilm-এর ফ্রি মিউজিক, সাউন্ড ইফেক্ট, ভয়েস আর স্টিকার।

### কমিউনিটি

কমিউনিটি হলো OpenFilm-এ যা কিছু যোগ করা যায়, তার সবকিছুর জন্য একটি ওপেন স্ট্যান্ডার্ড, আর যে-কেউ এর জন্য বানাতে পারে।

- **প্লাগইন** নতুন এডিটর আর বাইরের সার্ভিসের কানেক্টর দিয়ে OpenFilm-কেই বাড়িয়ে তোলে। OpenFilm-এর নিজের এডিটরগুলোও প্লাগইন, অন্য সবার প্লাগইনের মতো একইভাবে বানানো।
- **স্কিল** এজেন্টকে কোনো এক ধরনের ভিডিও বানানোর পদ্ধতি শেখায়।
- **অ্যাসেট** হলো মিউজিক, সাউন্ড ইফেক্ট, ট্রানজিশন, ইফেক্ট, টেক্সট স্টাইল, স্টিকার আর টেমপ্লেট।
- **উদাহরণ** হলো সম্পূর্ণ প্রজেক্ট, যা থেকে শেখা যায় এবং রিমিক্স করা যায়।

প্রতিটিই একটি সাধারণ ফোল্ডার। OpenFilm-এর Community উইন্ডো থেকে যোগ করুন, অথবা নিজেই বানান: [প্লাগইন বানান](packages/openfilm/plugins/README.md), [স্কিল লিখুন](https://github.com/openfilm/community/blob/main/SPEC.md), [অ্যাসেট শেয়ার করুন](https://github.com/openfilm/community/blob/main/assets/CONTRIBUTING.md), কিংবা শেষ করা ভিডিও উদাহরণ হিসেবে শেয়ার করুন, তারপর [openfilm/community](https://github.com/openfilm/community)-তে তালিকাভুক্ত করুন।

### যেভাবে কাজ করে

একটি ভিডিও মানে `film.html` থাকা একটি ফোল্ডার: ক্লিপের ট্র্যাক, CSS দিয়ে স্টাইল করা।

```html
<meta name="viewport" content="width=1920, height=1080">
<section>
  <iframe src="title.html#t=0,4"
          overrides='[{"at":"h1","text":"Aura Pods","style":{"color":"#7fd4ff"}}]'></iframe>
</section>
<section>
  <video src="assets/footage.mp4#t=12,18" at="4" style="left: 160px; top: 90px; width: 1600px; height: 700px"></video>
</section>
<section>
  <audio src="assets/music.mp3" volume="0.6"></audio>
</section>
```

প্রতিটি শট একটি ওয়েব পেজ, যার একটিমাত্র ফাংশন `frame(t)` ব্রাউজার যা কিছু আঁকতে পারে তা দিয়েই (three.js, WebGL, canvas, SVG, CSS, GSAP, ভিডিও) যেকোনো মুহূর্ত আঁকে এবং একই `t`-এর জন্য সবসময় একই ছবি আঁকে, তাই যেকোনো মেশিনে একইরকম রেন্ডার হয়, এজেন্ট প্রতিটি ফ্রেম যাচাই করতে পারে, আর Remotion বা HyperFrames-এর মতো কোনো ফ্রেমওয়ার্কের দরকার পড়ে না।

```js
window.film = {
  frame(t) { /* t সেকেন্ডের সম্পূর্ণ ছবিটি আঁকো */ },
};
```

**আপনার বদল আপনারই থাকে।** কোনো শটের ভেতরে হাতে কিছু বদলালে, যেমন তার লেখা, রং, অবস্থান বা আকার, OpenFilm সেটি পেজের কোডে নয়, ক্লিপের `overrides`-এ সংরক্ষণ করে। এজেন্ট পেজটি নতুন করে লিখলেও আপনার বদল বহাল থাকে। পূর্ণাঙ্গ ফরম্যাট আছে [SPEC.md](packages/openfilm/SPEC.md)-তে।
