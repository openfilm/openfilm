### เกี่ยวกับ

OpenFilm เปลี่ยนเอเจนต์เขียนโค้ดตัวไหนก็ได้ให้เป็นเอเจนต์ทำวิดีโอ พร้อมเอดิเตอร์ที่ให้คุณแก้ได้ทุกอย่างที่มันสร้าง

คุณกับเอเจนต์ทำวิดีโอเรื่องเดียวกัน ไปพร้อมกันแบบเรียลไทม์ เอเจนต์เปลี่ยนอะไร คุณเห็นทันทีขณะที่มันเกิดขึ้น คุณเปลี่ยนอะไร เอเจนต์ก็เห็นเช่นกัน งานส่วนใหญ่เอเจนต์ทำให้ ส่วนคุณแค่ชี้ไปที่อะไรก็ได้แล้วขอให้แก้ หรือจะลงมือแก้เองก็ได้

- **เอเจนต์ทำวิดีโอให้** ใช้ Claude Code, Codex, เอเจนต์เขียนโค้ดตัวอื่น หรือเอเจนต์ที่มีมาในแอปเดสก์ท็อปก็ได้ มันหาฟุตเทจ เพลง และเสียงพากย์ เขียนทีละช็อตแล้วตัดต่อเข้าด้วยกัน ให้คุณดูไปพร้อมกัน
- **ชี้ที่อะไรก็ได้** คลิปหนึ่ง ช่วงเวลาหนึ่ง ช่วงหนึ่งบนไทม์ไลน์ จุดหนึ่งในเฟรม ซับไตเติลหนึ่งบรรทัด หรือการ์ดหนึ่งใบบนแคนวาส ชี้แล้วบอกว่าต้องการอะไร เอเจนต์ก็รู้ทันทีว่าคุณหมายถึงตรงไหน
- **แก้เองด้วยมือ** ในช็อตไหนก็ได้ คุณย้าย ย่อขยาย และหมุนองค์ประกอบใดก็ได้ พิมพ์ข้อความใหม่ เปลี่ยนสี ฟอนต์ และขนาด แล้วใส่แอนิเมชันได้ละเอียดถึงทีละคำ บนไทม์ไลน์ คุณตัดหัวท้าย แยก และสลับลำดับคลิป ปรับความเร็ว ระดับเสียง และเฟด ครอป เกรดสี และลบพื้นหลัง รวมถึงแก้ซับไตเติลและเสียงพากย์ได้ ทุกอย่างที่คุณแก้จะบันทึกลงไฟล์เดียวกัน และเอเจนต์ก็ทำต่อจากตรงนั้น

### การติดตั้ง

**แอปเดสก์ท็อป** [ดาวน์โหลดสำหรับ macOS หรือ Windows](https://github.com/openfilm/openfilm/releases/latest) ทุกอย่างที่ต้องใช้มีมาให้ครบ ไปจนถึงเอเจนต์ในตัว และถ้าคุณใช้ Claude Code หรือ Codex อยู่แล้ว ก็ใช้ร่วมกันได้เลย

**เอเจนต์เขียนโค้ดของคุณเอง** เพิ่มสกิล (ต้องมี Node 22.2+ และ ffmpeg) แล้วขอให้มันทำวิดีโอ:

```bash
npx skills add openfilm/openfilm
```

> ทำวิดีโอเปิดตัว CLI ของฉันยาว 20 วินาที ใส่เพลงด้วย

### เอดิเตอร์

เอดิเตอร์แต่ละตัวคืออีกวิธีหนึ่งในการทำงานกับวิดีโอเรื่องเดียวกัน และในทุกตัว คุณกับเอเจนต์ทำงานไปด้วยกัน OpenFilm มาพร้อมเอดิเตอร์สี่ตัว และกำลังพัฒนาเอดิเตอร์ทางการเพิ่มอีกสำหรับคนหลายแบบ ตั้งแต่แบบเรียบง่ายที่ใครก็หยิบไปใช้ได้ ไปจนถึงเวิร์กเบนช์ระดับมืออาชีพสำหรับคนที่ต้องการ เอดิเตอร์ทำตามมาตรฐานเปิดของคอมมูนิตี้ ใครก็สร้างเองและแชร์ได้

- **ห้องฉาย**: ดูวิดีโอเต็มจอ คลิกที่ช่วงเวลาหนึ่ง ลากคลุมช่วงหนึ่ง หรือวงส่วนหนึ่งของเฟรม แล้วเอเจนต์ก็รู้ว่าคุณกำลังชี้ที่อะไร
- **ตัดต่อ**: ไทม์ไลน์เต็มรูปแบบสำหรับคลิป ข้อความ ซับไตเติล เสียงพากย์ และเสียงประกอบ ย้าย ย่อขยาย และปรับสไตล์อะไรก็ได้ในช็อต ส่งออกเป็นวิดีโอ หรือนำไทม์ไลน์ไปทำต่อใน Final Cut Pro, Premiere Pro หรือ DaVinci Resolve
- **แคนวาส**: บอร์ดสำหรับวางแผน มีโน้ต รูปภาพ คลิป และเสียงพากย์วางเรียงเคียงกัน สร้างแต่ละชิ้นด้วยบริการของคุณ แล้วส่งขึ้นไทม์ไลน์ตามลำดับ
- **เกรดสี**: เกรดสีทุกคลิปด้วยสโคป วงล้อสี และเคิร์ฟ ทั้งจากฟุตเทจ log ของกล้อง หรือด้วย LUT `.cube` พรีวิวเห็นแบบไหน ส่งออกก็ได้แบบนั้น

ทั้งสี่ตัวใช้ไลบรารีเดียวกัน ฟุตเทจของคุณเองจัดเก็บเป็นโฟลเดอร์ ลิงก์ไว้แทนการคัดลอก ย้ายที่ไปก็ยังหาเจอ อยู่คู่กับเพลง เสียงเอฟเฟกต์ เสียงพากย์ และสติกเกอร์ฟรีของ OpenFilm

### คอมมูนิตี้

คอมมูนิตี้คือมาตรฐานเปิดสำหรับทุกอย่างที่เพิ่มเข้าไปใน OpenFilm ได้ และใครก็สร้างได้

- **ปลั๊กอิน** ขยายตัว OpenFilm เองด้วยเอดิเตอร์ใหม่ ๆ และตัวเชื่อมต่อกับบริการภายนอก เอดิเตอร์ของ OpenFilm เองก็เป็นปลั๊กอิน สร้างด้วยวิธีเดียวกับของทุกคน
- **สกิล** สอนเอเจนต์ถึงวิธีทำวิดีโอแบบใดแบบหนึ่ง
- **แอสเซ็ต** คือเพลง เสียงเอฟเฟกต์ ทรานซิชัน เอฟเฟกต์ สไตล์ข้อความ สติกเกอร์ และเทมเพลต
- **ตัวอย่าง** คือโปรเจกต์ที่เสร็จสมบูรณ์ ไว้ศึกษาและนำไปรีมิกซ์

แต่ละอย่างเป็นแค่โฟลเดอร์ธรรมดา เพิ่มได้จากหน้าต่าง Community ใน OpenFilm หรือสร้างเอง: [ทำปลั๊กอิน](packages/openfilm/plugins/README.md) [เขียนสกิล](https://github.com/openfilm/community/blob/main/SPEC.md) [แชร์แอสเซ็ต](https://github.com/openfilm/community/blob/main/assets/CONTRIBUTING.md) หรือแชร์วิดีโอที่เสร็จแล้วเป็นตัวอย่าง จากนั้นลงรายการไว้ใน [openfilm/community](https://github.com/openfilm/community)

### หลักการทำงาน

วิดีโอหนึ่งเรื่องคือโฟลเดอร์ที่มี `film.html`: แทร็กของคลิปที่จัดสไตล์ด้วย CSS

```html
<meta name="viewport" content="width=1920, height=1080">
<section>
  <iframe src="title.html#t=0,4"
          overrides='[{"at":"h1","text":"Aura Pods","style":{"color":"#7fd4ff"}}]'></iframe>
</section>
<section>
  <video src="assets/footage.mp4#t=12,18" at="4" style="left: 160px; top: 90px; width: 1600px; height: 700px"></video>
</section>
<section>
  <audio src="assets/music.mp3" volume="0.6"></audio>
</section>
```

แต่ละช็อตคือหน้าเว็บที่มีฟังก์ชันเดียวคือ `frame(t)` ซึ่งวาดช่วงเวลาไหนก็ได้ด้วยทุกอย่างที่เบราว์เซอร์วาดได้ (three.js, WebGL, canvas, SVG, CSS, GSAP, วิดีโอ) และวาดภาพเดิมเสมอเมื่อได้ `t` เดิม จึงเรนเดอร์ออกมาเหมือนกันทุกเครื่อง เอเจนต์ตรวจได้ทุกเฟรม และไม่ต้องพึ่งเฟรมเวิร์กอย่าง Remotion หรือ HyperFrames

```js
window.film = {
  frame(t) { /* วาดภาพที่สมบูรณ์ ณ วินาทีที่ t */ },
};
```

**สิ่งที่คุณแก้ไม่หายไปไหน** เมื่อคุณแก้อะไรในช็อตด้วยมือ เช่น ข้อความ สี ตำแหน่ง หรือขนาด OpenFilm จะบันทึกไว้ใน `overrides` ของคลิป ไม่ใช่ในโค้ดของหน้าเว็บ ต่อให้เอเจนต์เขียนหน้าเว็บใหม่ สิ่งที่คุณแก้ก็ยังมีผลอยู่ ดูรูปแบบไฟล์ทั้งหมดได้ที่ [SPEC.md](packages/openfilm/SPEC.md)
