# 剪映导出优化：实现与整片实测

T12 同参数整片基线为 **5,846,462,918 bytes / 680.151 秒**。优化后的首次导出为 **2,936,610,530 bytes / 464.007 秒**：体积减少 **49.8%**，耗时减少 **31.8%**。再次导出 **17.309 秒**；只改 p25 的文字后 **22.248 秒**，其余 32 个渲染产物复用成功。

源码已在工作区实现，已经生成可打开的剪映验收草稿，并在剪映中实际导出完整成片。安装包尚未重新发布。

## 测试对象与口径

- Apple M5、16 GiB 内存、macOS arm64、FFmpeg 8.1.1、剪映专业版 11.8.0。
- 同一个源工程副本，1080×1920、30 fps，使用真实 Studio `createExports()` 的剪映导出路径，保留音轨、字幕、完整原视频及可编辑控制。
- 首轮截图对应的历史草稿为 5,585,786,936 bytes（5.202 GiB）。它与本轮同参数重导出的基线不完全相同，下面的优化百分比统一使用本轮基线，避免混用。
- 每组为一次实测；计时包含探测、绘制、后处理、内容校验与工程封装。不是多轮统计的性能保证。
- 测试使用冻结的导出实现快照，避免其他工作区修改干扰。末次又补了未验证 CPU 架构回退、精确 NTSC 时钟、远程资源不缓存、FFmpeg 版本失效和导出中编辑的缓存保护；这些保护不改变本片全本地资源、M5、30 fps 的媒体处理路径。

| 场景 | 工程逻辑体积 | 导出耗时 | 渲染产物缓存命中 |
| --- | ---: | ---: | ---: |
| 修改前，同参数冷导出 | 5.846 GB | 680.151 s（11:20） | 不适用 |
| 优化后，冷导出 | 2.937 GB | 464.007 s（7:44） | 0/33 |
| 不改内容，再次导出 | 2.937 GB | 17.309 s | 33/33 |
| 只把 p25 的 HUD「价值」改成「价值复测」 | 2.937 GB | 22.248 s | 32/33，仅 p25 重做 |

这里的 GB 是十进制，包含工程附带的完整原视频、声音和图片。剪映首页对验收稿显示约 2.5G，其素材统计与整个文件夹的统计范围不同。文字修改只发生在测试副本，测试后已恢复。

每秒采样的「输出目录＋项目缓存」逻辑体积峰值从 **6,945,263,555** 降至 **3,462,837,942 bytes**。这是文件逻辑大小，不能当作 APFS 实际占用或精确磁盘瞬时峰值。既有视频 seek 缓存约 259 MB 仍保留；新建的完成产物缓存本身只存索引，不隐藏复制一套 GB 级媒体。

## 已实现的改动

1. **PNG 精确去重直接移除重复包。** 显式关闭 bitstream filter 的字节修改；保留原 PTS、首末样本和音轨。取消原有的 50% 去重门槛，省去固定的第二次 PNG 编码。
2. **透明页面只做一次必要的 PNG 编码。** 用真实照片、纹理页选择 level 3 / SUB，保留统一 RGBA。浏览器 PNG 直接拷贝封装的候选方案整片变大到 7.142 GB，已撤回。
3. **裁掉整段都透明的外围画布。** 扫描每个存储帧的全部 alpha，包含 alpha=1 的阴影；包围盒向外对齐到偶数像素，并写回素材尺寸与位置。覆盖两段圆形 PiP、字幕备用层和头像。稀疏帧在 25 fps 下的末帧时长问题已修复。
4. **按实际透明区间使用无损表示。** 本片 18 页保留 83 帧透明片头，2961 帧不透明主体使用 `libx264rgb -crf 0`。每个分段发布前，源与产物全部 RGBA 像素的 SHA256 必须一致，帧数必须一致，文件总量至少减少 10%；不满足就保留 PNG。相邻片段在原帧网格上衔接。
5. **RGB 仅在验过的解码环境启用。** 当前限定 macOS arm64 的剪映 11.8.0，其他平台、架构、编辑器、版本及显式 PNG 模式保留 PNG。该版剪映会再次收缩标为全范围的 RGB，已通过真实 RGBA 页面回读定位；采用经过回读的 TV 标记，RGB 样本本身不变。未把普通有损 H.264 当作无损替代。
6. **完成产物可按内容复用。** 对页面和递归本地依赖做完整内容哈希，同时纳入浏览器、FFmpeg、渲染代码、字体、尺寸、帧率与编码配置。链接素材跟踪解析后的原文件；同尺寸、保留修改时间的替换也会失效。生成索引前后核对绘制时的依赖快照，导出中编辑过的产物不标为新内容。产物缺失、损坏或任何分段损坏时重新生成。外部网络资源无法可靠按本地内容校验，含此类请求的页面不进入完成产物缓存。
7. **绘制与后处理共用资源预算并可观测。** 限制后处理叠加；导出任务记录每个素材的绘制、后处理、缓存写入时间、大小、裁剪和分段信息。对齐已有 PR #450 的原生 fit/position 与中性 CSS 处理，减少不必要烘焙。

| 素材 | 基线 | 优化后 |
| --- | ---: | ---: |
| p02 | 595.84 MB | 482.61 MB |
| p16 | 583.78 MB | 231.13 MB |
| a-pip-1 | 347.66 MB | 301.18 MB |
| a-pip-2 | 199.33 MB | 172.84 MB |
| 字幕备用视频 | 2.55 MB | 1.56 MB |

噪点、渐变、文字微动、透明度和阴影没有为压缩而静态化。画布、帧率、剪辑时间和字幕设计沿用原工程。

## 像素、声音与时间线验收

**同次渲染内的无损媒体处理通过。** 18 组 RGB 分段在实际导出过程中逐段对全部 RGBA 样本校验；单元与集成用例覆盖稀疏时间戳、细微 alpha、阴影、位置补偿、首末帧和长去重表达式。裁剪素材依据实际序列化的剪映缩放与坐标恢复画布后比较，不能只按预期裁剪参数做自证。

**独立两次整片渲染没有达到所有帧 bit-exact。** 对 34 个对应媒体对象、共 12,206 个图层帧做全量比较：11,861 帧 MD5 相同。差异包括 1 帧旧 H.264 封面被原始 PNG 替代，以及 p02/p09/p11/p12/p22 的 344 个页面帧；这些帧已完整列入证据，没有忽略失败项或改用模糊指标宣布全部一致。

进一步用未修改的旧导出器单独重跑 p09/p12，也不能与旧整片基线全部一致：p09 的 178 帧中有 58 帧不同；p12 单独重跑的 212 帧与新产物对应帧相同，但与旧整片基线前 212 帧有 181 帧不同。原时间线的边缘取整使整片 p12 长度为 213 帧，单独放在 0 秒时为 212 帧。

对能够逐帧匹配旧基线的 p09 参考帧做像素定位，帧 30 只在 **(109,406) 的两个通道各差 1/255**，整帧 RGBA MAE 为 **0.0000002411**。证据支持浏览器绘制/分片条件的舍入差异；不能据这一个例子声称所有独立重绘差异都已逐像素量化。新编码发布前的同次输入输出校验不受独立绘制差异影响。

**裁剪相关图层的独立比较全部一致。** 两段 PiP、字幕备用层和头像共 7072 个图层帧，恢复原画布后与基线 RGBA 哈希相同；三段全屏口播共 1044 帧也一致。封面原始 PNG 与源文件 SHA256 一致，替代了此前的一帧 H.264 烘焙。

**声音与原片完整性通过。** 5 段随片 PCM 音轨逐样本 SHA256 与基线相同；12 个直接附带的原视频、头像视频、封面图片、配乐、旁白及音效文件与源工程的完整文件 SHA256 相同。原生声音的音量、静音、变速、淡入淡出及源句柄另由回归用例覆盖。

## 剪映实际回读

已通过应用界面完成 RGBA PNG、RGB 主体接缝和裁剪 PiP 的对照工程导出。默认有损 HEVC 回读的参考数据：

| 对照 | RGB MAE（0–255） | RGB 平均差 |
| --- | ---: | --- |
| PNG 重复片段对照 | 1.706 | −0.348 / −0.345 / −0.327 |
| PNG 对无损 RGB（修正标记） | 1.825 | −0.189 / −0.451 / −0.377 |
| PiP 重复片段对照 | 0.117 | −0.0048 / −0.0029 / −0.0015 |
| 原画布 PiP 对裁剪补偿 PiP | 0.173 | −0.0111 / −0.0008 / −0.0165 |

错误全范围标记曾使 PNG/RGB 的 MAE 达到 7.468，且出现约 `y≈0.86x+15` 的色阶收缩，该候选未采用。修正后没有该大幅色阶偏差。这里的回读包含剪映自身的有损编码误差，不能用于证明其内部合成是逐像素无损。

完整「社区体检T12 优化验收」也已在剪映中成功打开并实际导出：

- 1080×1920、30 fps、4028 帧、134.266667 秒。
- H.264 MOV，AAC 立体声，**199,899,564 bytes**。这是播放验收成片，不能与多图层可编辑草稿混为同一种体积。
- 完整解码成功；没有检测到持续至少 0.1 秒的近全黑画面或持续至少 2 秒的 −50 dB 静音。已核看整片采样画面中的圆形 PiP、字幕、文字和页面主体。
- 验收工程导入后的整个文件夹约 2.940 GB，包含剪映自行写入的工程记录和封面；基准表使用导入前 OpenFilm 完成产物的体积。
