# 资源中心：第一版实现

本版沿用文件管理器的空间和操作习惯，把跨项目整理、外部文件访问和项目内使用接到真实素材数据上。

## 命名与范围

| 名称 | 用户在这里做什么 |
| --- | --- |
| 资源中心 | 浏览项目和素材；项目页包含「我的项目 / 示例」顶部分栏 |
| 素材库 | 整理和预览可跨项目复用的个人素材、保存的片段与片段组，以及连接的外部目录 |
| 项目素材 | 使用当前项目的文件；可以切到同一份素材库或打开完整资源中心 |

素材库与项目素材共享素材入口和预览能力。浏览、星标、放入素材集都不会自动复制到项目，也不会自动添加时间线片段。

## 文件管理器结构（2026-11-15 更新）

本轮沿用文件资源管理器的固定位置与文件夹导航习惯，按用户要求简化为「固定 / 此电脑」两段，不单列主文件夹。固定项是快捷方式，和文件星标分开。文件管理器参考资料见 [Microsoft Support](https://support.microsoft.com/en-us/windows/experience/fileexplorer/file-explorer-in-windows)。应用使用实际可访问的位置，不添加没有接入的云盘、磁盘或网络服务。

- 固定：默认包含项目与素材库，两者不能取消固定。所有固定项均可拖动排序，每次打开资源中心默认进入第一项；旧偏好中缺失的默认入口自动补回。其他项目文件夹、素材文件夹可右键固定、取消固定，顺序在本机保存。
- 此电脑：侧栏保留项目、素材库和已连接外部目录的稳定位置入口。内容页提供位置卡片、素材集、最近文件、星标与离线入口，同时支持新建素材库文件夹、连接外部目录。逐层文件夹浏览放在内容区。
- 底部：存储设置与磁盘剩余空间。

侧栏只有一份，切换项目、示例和素材时保留导航及展开状态。示例只出现在项目页「我的项目 / 示例」分栏。素材库图标与对话栏一致，使用 LibraryBig。

素材库根目录就是实际保存素材的文件夹，保留目录层级；跨文件夹的聚合浏览只用于最近文件、星标、离线和素材集。连接的外部文件夹保持原结构。项目与素材库根目录均不可删除，界面与服务端共同保护。

路径、前进后退、上一级、搜索和文件命令合并成一条工具栏；小窗口把次要按钮收进更多菜单。项目和素材共用「查看」菜单，提供大图标、中等图标、小图标、详细列表，偏好跨区域保留。搜索覆盖当前浏览范围。

## 核心交互

- 单击选择并查看详情，双击或空格预览；方向键选择，Shift 连选，Cmd/Ctrl 多选与全选，空白处框选。
- 文件夹双击或回车进入，通过面包屑返回，Cmd/Alt + ↑ 回上一级。列表和网格共用同一份选中状态。
- 星标和加入素材集支持多选，素材集通过此电脑进入；移除素材集不删除原文件。
- 管理库内文件沿用现有的新建文件夹、重命名、移动、系统文件管理器显示和移到废纸篓。
- 外部目录在资源中心内用于浏览。文件写入操作不作用于连接的原目录；断开连接仅移除连接。
- 预览复用编辑器的源素材预览器，包括媒体播放和页面素材的播放桥接。

## 外部磁盘、NAS 与文件操作

素材库是应用的实际素材文件夹。外部磁盘、NAS 共享和普通文件夹统一作为连接位置，不新增一套素材分类。共享盘由操作系统完成挂载、身份验证和权限管理：参考 [Apple 连接共享电脑与服务器](https://support.apple.com/guide/mac-help/connect-mac-shared-computers-servers-mchlp1140/mac)、[Windows 网络文件共享](https://support.microsoft.com/en-us/windows/experience/connectivity-networking/file-sharing-over-a-network-in-windows)。连接时从系统文件夹选择器选择已挂载位置。

| 用户动作 | 结果 |
| --- | --- |
| 连接外部文件夹 / 共享目录 | 建立入口并留在此电脑，不自动打开或扫描；显式打开后浏览原目录结构，连接与固定是两个独立操作 |
| 复制到素材库 / 粘贴 | 生成独立库内文件；明确复制时不使用硬链接或自动转为引用 |
| 创建链接 / 粘贴链接 | 文件保留原位置，在目标库内文件夹建立链接 |
| 剪切 / 移动库内文件 | 改变库内位置，保留已有素材身份和整理关系；同名目标保留并提示 |
| 固定 / 取消固定自定义位置 | 只改变快速访问，不影响连接、文件或素材集 |
| 断开外部位置 | 移除连接，保留外部原文件 |
| 原位置离线 | 保留上次扫描的目录与整理记录，显示离线并可重新连接 |

全局资源窗口提供复制、剪切、粘贴、粘贴链接、复制到、创建链接到和 F2 重命名。复制或创建链接的目的地用逐层文件夹选择器选择，不把所有文件夹堆进超长菜单。大批文件使用进行中卡片，完成后显示实际数量与目标位置；同名复制自动生成新名称，不覆盖已有文件。外部素材拖到库内默认复制；库内拖动默认移动，Ctrl/Cmd 表示复制，Alt 表示创建链接。

原位置页明确显示真实路径、连接状态和文件管理器入口。应用内整理和复制不直接改写外部原目录；原目录的重命名、删除等操作使用系统文件管理器。素材库内沿用正常文件管理操作，链接入口本身可以改名、移动或移除；移除时明确告知原始文件仍保留。已保存的片段、片段组以携带依赖的复制方式复用。

## 与项目配合

详情面板明确给出目标项目和使用方式：默认“复制到项目”，也可以“使用原位置”。可复用的页面、片段与片段组携带依赖复制。

“加入项目”只准备项目文件，时间线不变。“插入时间线”只在当前编辑项目提供，随后复用已有项目文件。重复加入不会静默改变已选择的复制或引用方式。

使用情况展示通过这套流程记录的项目和时间线使用次数，不能视为对旧项目、任意外部复制行为的完整溯源。

库内移动和重命名保留素材身份、星标和集合关系，并修复可访问项目中已记录的引用。外部目录重新连接时同步修复对应引用。项目的独立副本保持独立。

## 大量素材与离线

普通浏览只读取当前打开目录的一层，不递归枚举子目录；连接外部目录只登记入口。刷新根目录、此电脑和整理记录不读取连接目标。此电脑的最近文件来自已访问索引，默认不探测媒体或加载缩略图。只有明确打开目录或预览文件后才访问对应外部内容。

卡片每批显示 160 项，缩略图靠近可见区域才请求。媒体信息仅对当前批次以有限并发读取并批量更新，切换目录或关闭窗口后取消继续读取。主动搜索可递归当前普通目录，但不会自动进入其他外部连接；最近、星标、离线和素材集查询已访问索引。目标目录选择器同样逐层读取。素材信息保存在库目录，项目加入记录保存在项目自身。

已扫描的外部目录断开后保留上次的文件记录和层级，明确标记离线。重新连接保留整理关系；已有且仍可读取的项目副本可以继续插入。

## 验证

服务端覆盖整理关系持久化、移动后的身份、离线目录记录、重连、原文件保留、项目引用修复、重复加入以及片段范围。真实浏览器流程覆盖项目内入口、键盘选择、预览、集合、离线与重连、加入与插入的区别，以及 420 个额外文件的分批显示与全量搜索。层级回归检查同一个侧栏跨区域和项目分栏保持不变，示例只出现在项目顶部分栏，且三种图标尺寸确实改变项目和素材卡片大小。额外覆盖项目文件夹固定、外部目录子文件夹固定后的页面重载、取消固定保留原文件、跨位置前进后退，以及窄窗口单行工具栏不溢出。

本轮验证还覆盖旧偏好恢复默认入口、从连接位置复制独立文件、粘贴链接、连续导航后立即剪切粘贴、目标目录选择、重名保留和移除链接不删除原文件。外部目录测试使用隔离的临时目录模拟磁盘与共享目录的离线、移动和恢复；没有使用真实 NAS 设备进行性能验收。

按需读取回归对未打开的连接目标拦截目录枚举和文件状态读取：连接后反复刷新根目录、此电脑及整理记录，两类调用均为零；显式打开后只枚举该层。浏览器回归覆盖连接后不自动打开、不预读源媒体，从此电脑新建文件夹、默认根入口拖动排序后重新打开进入第一项。删除接口回归确认项目与素材库根目录不可删除。

这版落实本机和外部目录的个人素材管理。云端服务连接、团队权限、语义索引和完整版本管理继续沿用调研方案的后续范围，不显示不可用的入口。
