Tending the media library. Like a file, or say you do not want it: what is not wanted is hidden in the library and
the file itself is never touched; both stay with the file when it is renamed or moved. New views of the whole
library: Liked, Not used yet (files no project has), Duplicates (files that are the same as another, group by group,
with the room keeping one of each would give back) and Not wanted. A file of a folder you added can be renamed where
it is, and moved to the Trash, where you can take it back; when a project links to the file, you are told which
before it goes.
