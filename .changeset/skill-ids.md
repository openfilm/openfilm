Every skill has a name wherever it is shared and searched, as the public skill directories name one: `owner/repo/name` on GitHub (`openfilm/skills/keynote`, `openfilm/openfilm/openfilm-edit`), `gitlab.com/group/repo/name` on GitLab. It is read from where the skill really came from (an official one's repository, the address one of the person's was added from), never from what the skill says of itself; one made here or added from a folder has its name only. The library's installed skills are a list: each line its mark, its title, that name under it and its switch, in parts headed with their counts, Import beside the search; a search finds a skill by that name too.
