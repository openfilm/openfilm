Add caption tracks directly from the captions panel or a caption track's menu. New tracks start with an editable
caption above the existing captions, and adding a caption uses the selected caption track. Empty caption tracks stay
on the timeline after their last caption is moved or deleted, so captions can be dragged back onto them.
Cross-track drags keep the caption's region position and selection, including when both tracks use the same region name.
