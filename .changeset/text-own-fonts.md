A font file of one's own (.ttf, .otf, .woff, .woff2) can be added from the Text inspector's font field: it is put in the project with its lines of words and listed under In this project, so it goes with the project. An exact frame waits for a font a clip's changes name, so an export no longer draws a line before its font has loaded. A new line of words says "Default text" whatever the app's language, as the library's things say their own words in English; a moving text template or sticker fills its card in the library.
