Studio: a clip swapped by a script or an agent outside Studio, and then swapped back, stays as written. The swap back read exactly like a version Studio had seen before, so it was taken for an old copy written again, and about 0.3 s later Studio put the clip back as the first swap had made it, without a word, until the app was restarted. Only what the person changed in Studio is kept over a write now; what came from another write is the latest write's. (#344)
