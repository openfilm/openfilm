Media made with the OpenFilm service no longer passes through it where it need not. The files a run names go straight to the service's storage, at an address given for each file alone, and a clip a model made comes straight from where its maker keeps it, instead of both travelling inside the run and its answer. A service that does not offer this yet gets the files inside the run as before. With the service, Seedance takes its reference pictures by address too, and fetches them itself.
