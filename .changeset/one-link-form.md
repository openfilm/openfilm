One way to point at a thing of the project, both ways: a link to it, with only what the web already has after `#` — an element's id, and a time and a part of the picture as W3C Media Fragments write them (`film.html#t=12.5`, `film.html#t=12,16`, `film.html#t=12.5&xywh=640,200,320,180`), the same `#t=` the film's sources are cut with. What the person points at reaches the agent as numbered links to where it is; the agent points back with Markdown links to the project, which the chat draws as the same pills (lit in Studio under the pointer, shown there when pressed), in place of the bracketed tokens it was taught before (those in kept conversations are still drawn). A link to a part of the picture opens in the workbench shown, which lights it. Plugins read links with `links` from `openfilm/studio`, and the plugin guide says how a plugin names its things.
