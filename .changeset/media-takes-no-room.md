Media brought in from this computer no longer takes room twice. On the same disk it comes in as a file of the
project's own that takes no extra room (on a Mac's disk, which Studio's copy did not manage before; elsewhere, the
same file under a second name, which stays when the original is deleted). From another disk, media of 100 MB or more
stays where it is and is linked, and Studio says so; smaller files are copied as before. "Link files…" still links
whatever the size.

Settings → General → Storage shows what the projects take on disk and how much of it is cache, with each project's
share, and clears the cache: what the preview and exports made is made again when it is needed. Versions,
conversations and the work itself are never touched.
