What `openfilm` tells an agent is now a system prompt of a few lines (`SYSTEM_PROMPT.md`, in place of `MANUAL.md`): where the agent is, how to be with you, and that skills say how each kind of work is done. It no longer says what a film is or names any command for making one: that is each skill's, read when a task needs it, so an agent starts with far less to read. OpenFilm's own skills are listed after it, each by what its own description says, and only those whose plugin is on. The desktop app's own agent and the other agents it starts are given the same text.
