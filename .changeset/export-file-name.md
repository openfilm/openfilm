Export lets you name the files before they are made: the name beside "Save to" starts as the project's, and every file of that export takes it, each adding what it is (the platform, the size). Characters a file system refuses are dropped and the extension stays Studio's. Scrolling the export dialog with a mouse wheel or a trackpad no longer makes the window flicker on macOS.
