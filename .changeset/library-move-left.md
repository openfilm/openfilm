Moving the library to another disk no longer counts a project as not moved when the trash will not take its old folder (on Windows, the Recycle Bin refusing one bigger than it holds): the copy on the new disk is whole, so it is the project from then on, and Studio says which old folders stay on the old disk, for the file manager to delete. Before, the person was told the move failed while a full copy sat in the new library unlisted.
