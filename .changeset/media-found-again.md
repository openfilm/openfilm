Media that was moved or renamed is found again without asking. Studio records each media file of a project by a
fingerprint of its bytes. A linked file or folder that was renamed, moved to a folder nearby, or is on a disk that
came back under another name is connected again, and a file renamed inside the project's own folder has its clips
pointed at it. Studio says how many it found. For what it cannot find on its own, the viewer and the media pane say
what is missing and take a folder to look in: everything found there is connected at once. A clip whose link leads
nowhere is now marked as missing on the timeline.
