Skills: Discover shows the openfilm/skills index as it is now on GitHub, read as Studio starts and again behind it each time it opens, and no longer a copy that came with OpenFilm, so a skill added there shows and one taken away is gone; while it is first read, its tiles' places show, never an empty page. Without a connection it shows what it last read, and says so. An empty conversation's cards are Discover's skills too, and one can be tried there before it is installed. Installing a skill downloads it at the version Discover shows, and it stays that version, offline too; when a newer one is out, the skill says so and Update brings it, the old one going to the trash. A skill taken out of Discover stays installed and working, marked as no longer there. The ten starter skills are retired. `openfilm skills` lists the installed ones as installed.
