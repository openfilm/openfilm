Skills: Discover shows the openfilm/skills index as it is now on GitHub, read again as it opens (once in ten minutes), and no longer a copy that came with OpenFilm, so a skill added there shows and one taken away is gone. Without a connection it shows what it last read, and says so. Installing a skill downloads it at the version Discover shows, and it stays that version, offline too; when a newer one is out, the skill says so and Update brings it, the old one going to the trash. A skill taken out of Discover stays installed and working, marked as no longer there. The ten starter skills are retired. `openfilm skills` lists the installed ones as installed.
