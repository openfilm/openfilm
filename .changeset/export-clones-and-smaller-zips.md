On a Mac, exporting a project as a folder, duplicating a project and collecting original media into an editing project now clone large files instead of writing them again: a project with gigabytes of footage is copied at once and takes no more room on the same disk. A project exported as a zip is smaller: pages, scripts, data, subtitles and TrueType fonts are compressed, while footage, pictures and sound stay as they are. Diagnostic files are smaller for the same reason.
