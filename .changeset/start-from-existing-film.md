Studio's Projects page can start from an existing film: "Open folder…" (a folder browser in the web editor, the app's own dialog in the desktop app), "Get from GitHub…" (a repository or a folder in one, copied into the projects library without its git history), and a row of example films. A project whose folder moved can be located again. `openfilm open <github url>` fetches a film the same way.
