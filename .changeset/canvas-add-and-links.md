`openfilm canvas add <file…>` puts files of the project on the canvas the person has open, in a row below what is there, as the pair of `openfilm edit add`. A link to a node on another of the project's canvases (`.film/canvases/<id>.json#<node>`) shows that canvas first, then the node. The canvas shows sooner the first time: an empty board's double-clicking cursor starts moving a moment after the board is shown.
