All media: the media pane's side rail has a new place beside Imported, with every project's media and the folders you
add, newest first. Each file shows once, however many projects have it, and says which project or folder it is
from; searching finds a project's or a folder's name too. Click one to watch it in the viewer; drag it onto the
timeline (or press Enter) to use it, and it comes into the project the way imported media does, taking no extra room
where the disk allows. Used again, it is the file already in the project.

"Add folder" adds a folder of your own media without copying or moving anything; its menu shows the folders added,
opens them, and removes them (the folder and its files stay as they are).
