What agents read is shorter and says only what is true. `openfilm get` offers an agent the library's music, sound effects and stickers; transitions, effects, filters, texts and templates stay in Studio's library for you to pick. `openfilm --help` leaves out `open` and `update` for an agent in the desktop app, and no longer lists the canvas's commands as OpenFilm's own: the canvas skill says them. The media skill is half as long, `openfilm skill <name>` prints a skill without its front matter, the app's own agent is told which plugins are off as other agents are, and `openfilm edit` points to each command's `--help` rather than to a skill it does not have.
