The manual is a page: what a film is, and OpenFilm's own skills, which hold the rest. `edit` says how a film is made and seen, `media` how its music, sounds and pictures come from the library or a service, `canvas` how the canvas is read and changed. Every agent has them, always on and in no library, and reads one when a task needs it: `openfilm skill <name>` prints it with the command as it runs there. The desktop app's own agent starts from a short prompt (where it is and how it talks with the person) with these skills listed after it, in place of the whole manual.
