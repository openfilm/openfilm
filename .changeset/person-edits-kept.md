Studio: what you change while an agent works stays. An agent often writes film.html whole, from a copy it read before your edits; Studio now merges that write into the film as git merges, from the version the agent's copy was: what only the agent changed is taken, what you changed since stays, and where you both changed the same thing, yours stands. You are never asked anything. The agent is told what stood over its write, in its next `openfilm` command (on stderr) or the chat's next message, so it can read the film again. Subtitle edits and the page links Studio rewrites are merged the same way, line by line. Every merge keeps the agent's own file aside in the project's history first.
