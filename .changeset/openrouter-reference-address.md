At OpenRouter, Seedance fetches a voice recording (`--voice`) or a reference clip only from a web address. A run that can make a temporary address sends the file by that address; OpenFilm's own service is one such run. A run with your own key says so before anything is sent, and points to fal, which takes the file straight from the project. Previously OpenRouter refused the request with "Only HTTPS URLs are allowed".
