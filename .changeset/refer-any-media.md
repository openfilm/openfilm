A file of All media or of Saved can be pointed at for your agent: its menu has "Reference in chat", which brings the
file into the project first, so the agent is given a file it can use as it is. A file a service made tells the agent
the prompt, service and model it was made with, so "one more like this, at night" works. And a file brought in from
another project keeps how it was made.
