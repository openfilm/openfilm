Your media library at a project's side: the assets drawer's Media has "My library" between Imported and Favorites.
Pick a folder you added, Saved, a view (Newest, Liked, Not used yet, Generated) or another project from its menu, or
search all of it. Click a file to watch it, drag it onto the timeline or double-click it to put it in the film: it
comes into the project the way imported media does, taking no extra room where the disk allows, and used again it is
the file already there. "Open the media library…" opens the whole library to add folders and tidy up. The files you
kept in Saved are a place in the library too.

Your agent knows your library: `openfilm get my-media` searches the media you keep on this computer and in your other
projects by name, folder, project and prompt, says which you liked and which no project uses yet, and
`--take <id>` brings one into the film. It is told to look there first, before OpenFilm's library and before making
anything new.
