A paid run the OpenFilm service refused (no balance, a limit, the model failing) no longer comes back the same each time: the same settings make a new run once topped up or retried; a run with no answer from the service is still kept to recover. Studio waits for an OpenFilm video as long as the service can take to make it, short requests that hear nothing are asked again sooner, and a voice spoken from the voice library is recovered after an interruption instead of made and paid again.
