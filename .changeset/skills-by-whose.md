The library's installed skills are sorted by whose they are: All, Imported (the person's own and this project's, with Import first in the desktop app), OpenFilm (its system skills and the community's installed) and Agents (the skills the person's agents have of their own). OpenFilm's system skills, `edit`, `media` and `canvas`, are listed there with a title and a summary in each language, and each can be turned off: one turned off is given to no agent, and the desktop app's own agent is no longer told to read `edit` when it is off. Agents are given them in that order, edit, media, canvas.
