Agents can use the browser: Claude Code, Codex and OpenFilm's own agent open, read, click, type in and take screenshots of the tabs of the project they work in, while you watch in the Browser workbench, which comes up and says which agent is using the tab. Take Over hands the tab to you until you hand it back. An agent reaches only its own project's tabs. What it reads from a page is marked as the page's words, never instructions. A form it would send waits for your Send, showing where it goes and what it sends; downloads, site permissions and other apps' links still ask you as before.
